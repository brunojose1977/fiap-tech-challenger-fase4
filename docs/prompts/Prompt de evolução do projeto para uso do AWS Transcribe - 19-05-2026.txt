Prompt de evolução do projeto para usar AWS transcribe e chatGPT

Agora crie uma etapa adicional no pipeline com o nome "aws-transcribe-audio-from-video-conversations" que execute as seguintes tarefas

- Em Python carregue do AWS S3 do bucket transcribe-violence-input-fiap-posttech-iadevs-tcfase04, todos os vídeos e áudios disponíveis
- Utilize o serviço AWS Transcribe para extrair os textos 
- Arquive o texto com o prefixo "transcribed-text-"+nome original do arquivo de áudio ou vídeo + ".txt" e gravar no bucket "transcribe-violence-output-fiap-posttech-iadevs-tcfase0"
- Na sequencia conecte ao ChatGPT GPT-5.4 para realizar a análise do texto e gerar classificação de risco para a avaliação do conteúdo texto, quanto ao indícios de risco de segurança, integridade, ameaça ou possível situação de crime ou risco de vida e integridade da mulher.

- Gravar uma avaliação em formato PDF formatado, de forma individualizada para arquivo com o prefixo "ChatGPT-5.4-avaliacao-conteudo-"+nome original do arquivo+".pdf e gravar no brucket "transcribe-violence-output-fiap-posttech-iadevs-tcfase0"
